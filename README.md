# FlowCRM

> CRM SaaS multi-tenant para pequenas e médias empresas, construído com Laravel (API) e React (SPA).
> Projeto em desenvolvimento — este README será expandido ao final de cada fase relevante.

## Status

🚧 Em desenvolvimento — Fase 0 (setup do projeto) concluída.

## Stack

- **Backend:** PHP, Laravel, Laravel Sanctum, MySQL
- **Frontend:** React, Vite, React Router, Axios, TanStack Query
- **Infraestrutura (planejada):** Docker, Docker Compose, AWS (EC2, RDS MySQL, S3, CloudWatch)

## Estrutura do repositório

```
flowcrm/
├── backend/     # API Laravel
├── frontend/    # SPA React (Vite)
└── docs/        # Documentação de arquitetura e decisões técnicas
```
